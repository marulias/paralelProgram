1. Задание лабораторной работы 
Разработать программу на языке C++ для перемножения двух квадратных матриц.

Требования:
Исходные данные: файлы matrix_A.txt и matrix_B.txt, содержащие значения матриц
Выходные данные: файл result.txt с результатом умножения
Обязательный вывод: время выполнения и объем задачи
Автоматизированная верификация с помощью Python/NumPy
Поддержка параллельных вычислений (2 потока)
Исследование зависимости времени выполнения от размера задачи

2. Теоретическая часть

Для двух квадратных матриц A и B размером n×n произведение C = A × B вычисляется по формуле:        C[i][j] = Σ(k=1 to n) A[i][k] · B[k][j]
Вычислительная сложность: O(n³)
Количество операций: 2n³ (n³ умножений и n³ сложений)
Для ускорения используется распараллеливание по внешним циклам. Матрица разбивается на блоки строк, каждый блок обрабатывается отдельным потоком.
OpenMP (Open Multi-Processing) — это стандарт для параллельного программирования на языках C/C++ и Fortran. Он позволяет легко распараллеливать программы с помощью специальных директив (прагм).

3. Реализация программы

lab1
 main.cpp          # Главный модуль
 functions.h       # Заголовочный файл
 functions.cpp     # Реализация функций
 matrix_A.txt      # Исходная матрица A (5×5)
 matrix_B.txt      # Исходная матрица B (5×5)
 result.txt        # Результат умножения 
 verify.py         # Скрипт верификации

 Программа написана на языке C++ с использованием стандартной библиотеки и OpenMP для параллельных вычислений. Проект состоит из трех файлов: main.cpp (главный модуль), functions.h (заголовочный файл с прототипами функций) и functions.cpp (реализация всех функций).

Функция readMatrix загружает матрицы из текстовых файлов, считывая размер и все элементы. Функция checkSizes проверяет совпадение размеров двух матриц. Основная вычислительная функция multiplyMatricesParallel реализует умножение с использованием OpenMP: устанавливает количество потоков (2) и директивой pragma omp parallel for collapse(2) автоматически распределяет итерации циклов между потоками. Время выполнения измеряется с помощью chrono с точностью до наносекунд.

Функция printMatrix выводит матрицу на экран. Функция saveResult сохраняет в файл result.txt подробный отчет, включающий размер матриц, количество потоков, время выполнения, количество операций (2n³), производительность в MFLOPS, исходные матрицы и результат.

Программа работает в автоматическом режиме: загружает матрицы из файлов, выполняет умножение и сохраняет результаты без участия пользователя. Для верификации используется отдельный Python-скрипт с библиотекой NumPy.

4. Сборка и запуск

# Компиляция с поддержкой OpenMP
g++ -fopenmp main.cpp functions.cpp -o matrix_mult.exe

# Запуск программы
.\matrix_mult.exe

# Запуск верификации
py verify.py
