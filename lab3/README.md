## 2. Реализация параллельного алгоритма

### 2.1. Схема распределения данных

При параллельном умножении матриц с использованием MPI используется следующая схема:
- Матрицы A и B рассылаются всем процессам с помощью `MPI_Bcast`
- Строки матрицы A распределяются между процессами
- Каждый процесс вычисляет свою часть результирующей матрицы C
- Процесс 0 собирает результаты от всех процессов

### 2.2. Распределение строк между процессами

int rows_per_process = n / size;
int remainder = n % size;

int start_row = rank * rows_per_process;
int end_row = start_row + rows_per_process;
if (rank == size - 1) {
    end_row += remainder;
}

### 2.3. Алгоритм умножения в каждом процессе
cpp
for (int i = start_row; i < end_row; i++) {
    for (int j = 0; j < n; j++) {
        double sum = 0;
        for (int k = 0; k < n; k++) {
            sum += A[i][k] * B[k][j];
        }
        C[i][j] = sum;
    }
}

## 5. Анализ результатов
### 5.1. Время выполнения
С увеличением количества процессов время выполнения в целом сокращается:
Для размера 2000×2000: с 142.62 сек (1 процесс) до 48.91 сек (8 процессов)
Наибольший эффект от параллелизации наблюдается для больших размеров матриц

### 5.2. Производительность
Производительность растет с увеличением количества процессов:
Максимальная производительность (568.10 MFLOPS) достигнута на 4 процессах для размера 200×200
Для размера 2000×2000 производительность выросла с 112.19 до 327.14 MFLOPS

### 5.3. Ускорение
Наибольшее ускорение (4.86) достигнуто на 4 процессах для размера 200×200
Для больших размеров ускорение ниже из-за накладных расходов на коммуникацию

### 5.4. Эффективность
Высокая эффективность наблюдается для малых размеров матриц
С увеличением размера эффективность снижается из-за роста времени коммуникации
